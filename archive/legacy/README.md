# Legacy / Historical Archive

**Archived on:** 2026 (via cleanup-legacy.ps1)

## Purpose
This folder contains historical development artifacts from the long evolution of the project:

- Early "OmniCapital" branded monolithic scripts (v1 → v8+)
- Multiple variants and experimental sweeps from the pre-modular era
- Old Compass v8/v9 backtest and review files
- Large monolithic "complete" algorithm dumps
- Old live trading attempts, manifests, deployment guides, and demo logs
- Experiment result pickles and one-off test scripts

These files represent **iterative development snapshots** before the current clean, modular implementation:

- `hydra_screener_local/` (SPEC v1.2 compliant, hybrid Python + Pine)
- `daily.py` ritual
- `core/`, `data/`, `utils/`
- Proper tests, packaging (`pyproject.toml`), HTML dashboard, live watcher, etc.

## What is here (categories)

- `omnicapital/` — All `omnicapital_v*.py`, `omnicapital_live*.py`, broker, data feed, notifications, vortex, old configs, manifests, and old logs.
- `compass/` — Legacy `compass_v8_*`, `COMPASS_V8_FOR_REVIEW.py`, `compass_v9_genius_backtest.py`, and related v* patches/optimization files.
- `experiment-results/` — Old `results_exp*.pkl`, `test_hold6.py`, and similar one-off result files.
- `cruft/` — Accidental files such as the 1.2 GB `nul` file and other noise.
